# Code of Conduct

## Our standard

This project expects direct, respectful, technically grounded collaboration.

Examples of expected behavior:

- Be specific and reproducible
- Critique code, product choices, and implementation details rather than people
- Explain tradeoffs clearly
- Keep disagreement focused on outcomes and evidence

Examples of unacceptable behavior:

- Personal attacks or harassment
- Repeated bad-faith arguing
- Dismissing contributors without technical substance
- Posting secrets, private credentials, or private user data

## Enforcement

Project maintainers are responsible for clarifying and enforcing this code of conduct. They may remove comments, close threads, or block participation when behavior harms collaboration.

## Reporting

If a conversation becomes disruptive, open a private channel with a maintainer instead of escalating the thread publicly.
